# BETA - @datf Add-ons

## WARNING! THIS IS A BETA REPOSITORY

This Add-ons repository contains edge builds of add-ons. Edge builds add-ons
are based upon the latest development version.

- They may not work at all.
- They might stop working at any time.

This repository was created for:

- Anybody willing to test.
- Anybody interested in trying out upcoming add-ons or add-on features.

If you are more interested in stable releases of these add-ons:

<https://github.com/datf/hassio-addons>

## Releases

Releases are based on Semantic Versioning, and use the format of
``MAJOR.MINOR.PATCH``. In a nutshell, the version will be incremented based on
the following:

- ``MAJOR``: Incompatible or major changes.
- ``MINOR``: Backwards-compatible new features and enhancements.
- ``PATCH``: Backwards-compatible bugfixes and package updates.
